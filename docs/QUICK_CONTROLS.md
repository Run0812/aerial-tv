# 快速控制

在电视的「控制中心 → 编辑快速控制」添加、修改、排序、隐藏或删除按钮。首次添加会打开快速控制区；关闭整个区域会保留已配置的按钮。之前已经启用的 Clash Meta 快捷按钮会自动迁移。

手机扫描电视「个性化」里的二维码后，打开网页的「更多 → 快速控制」。手机和电视使用同一份配置，改动会同步显示。网页也可以点「执行」，由电视发出请求。如果设置了家长密码，手机操作前先在这一节解锁。儿童与长辈模式下不能执行快速控制。Android 10 及以上，执行需要打开界面的动作时请先让 Aerial 显示在电视上。

可以添加以下类型（最多 12 个）：

- **Clash Meta**：切换已配置并授权的 Clash Meta 服务，支持项目既有的稳定版和 Alpha 适配。
- **打开应用**：从电视已安装的应用中选择。
- **自定义 Activity／广播**：填入目标应用文档给出的包名、已导出的组件类名、可选的动作和 URI。类名以 `.` 开头时补全为目标包名下的类。附加参数使用 JSON 对象，例如 `{"enabled":true,"channel":3,"name":"电视"}`；值支持字符串、布尔值和数字。目标应用需要公开相应组件及权限。

「请求已发送」表示电视已把请求交给 Android，实际动作由目标应用完成。快捷控制不需要调用 ADB 或安装目标应用。

测试包的网页端口是 `8791`，与正式版 `8790` 分开，测试时可同时保留两个版本。请使用测试版显示的二维码进入对应网页。
