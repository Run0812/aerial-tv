# 快速控制

打开电视控制中心的「编辑快速控制」，选择「＋ 添加控制」，从图标库点选需要的功能。内置控制包括 Clash Meta、网络设置、设备支持的蓝牙设置、静音、输入源和系统设置。Clash 需要先在应用内完成配置和 VPN 授权。快捷按钮会发送切换请求，连接状态可在 Clash 内确认。

## 添加其他应用的操作

在图标库选择「手动添加操作」，从应用文档填写公开入口。需要输入按钮名称、操作类型、应用包名和组件类名。类名可以用 . 开头，Aerial 会补全包名。发送广播时还需要填写 Intent 动作。数据 URI 和附加参数按应用的要求填写即可。

附加参数用 JSON 对象填写，值可为字符串、数字或布尔值。例如 {"enabled":true}。保存后，点图标才会执行。Aerial 支持公开、已启用且无需调用权限的 Activity 和清单广播接收器。这项功能无需设为系统桌面。升级后，过去通过桌面权限发现的快捷方式会从面板中移除。

## 编辑和使用

在编辑模式选择已添加的图标，可以改名、移动、隐藏或移除。手动添加的图标还可以编辑操作参数。最多保留 12 个控制。关闭快速控制区会保留配置。

手机扫描 Aerial「个性化」中的二维码，打开「更多 → 快速控制」。手机和电视共用配置。点「＋」添加，点「编辑」后可拖动图标下方的把手排序。若另一端已修改配置，请根据更新后的列表重试。

如果设置了家长密码，手机操作前先在快速控制区解锁。儿童与长辈模式下不能执行快速控制。从手机执行手动操作时，请让 Aerial 显示在电视上。
